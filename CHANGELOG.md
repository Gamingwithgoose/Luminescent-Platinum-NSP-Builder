# Changelog

## 1.0.0 — October 28, 2026

- Windows build-only launcher with local Python dependency setup.
- User-supplied Brilliant Diamond 1.3.0, Luminescent Platinum 2.2F BD, and console keys.
- Required-file, supported-version, complete input-layout, and asset-fingerprint checks.
- Baked executable patches, added module, distinct build ID, and separate application/save identity.
- Optional custom artwork; generated LP emblem when no artwork is provided.
- Independent finished-package verification before publishing to `Release`.
- Input-folder walkthrough, installation instructions, troubleshooting, and tool/source licenses.
